Troubleshooting
===============

Contact
-------

Before contacting us, please make sure you have read the documentation and checked the :ref:`Known-Issues`.

Reported problems, and the ones we already fixed, are listed in the `GitHub issue tracker
<https://github.com/BSC-ES/automatic-performance-profiling/issues>`_. Check it before opening a new
issue, and open one there if your problem is not listed yet.

If you still have questions/issues, please contact us at `roc.salvador@bsc.es <roc.salvador@bsc.es>`_.
