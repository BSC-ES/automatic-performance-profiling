Compilation efficiency compares the performance of the same test when it is run with binaries built with different compiler flags, libraries or compilers. All the cases use the same model configuration and the same number of processing units, so the differences in throughput can be attributed to the build.

The section presents, for every build, the geometry of the case and the throughput obtained, followed by a comparison table and a comparison plot that gather all the builds in a single figure. The comparison table names the metric with its unit in every column header and gives the value of each case as a mean and a standard deviation, followed by the difference in \% with respect to the first build: that column is the share of the value of the first build that a build gains or loses. There is no ideal reference line here: the best build is the one with the highest throughput, and which one that is depends on the compilers and libraries available on the platform.
