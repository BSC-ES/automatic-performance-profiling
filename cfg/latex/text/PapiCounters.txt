This section puts two hardware counters of the tracked user functions against each other. Every point is one function in one traced case, with both counters averaged over the threads of that case, and the arrows join the consecutive cases of the same function, so the direction of an arrow is how that function moves as the number of processing units grows. The axes name the two counters and their unit, so the position of a point gives the two values of the function in that case and its path the evolution of the function along the cases.
