The table below lists the configuration values that are common to all the tests in this report. Values that apply to a single test are listed in the section of that test. When present, \emph{Resolution} is the experiment resolution, \emph{Timesteps} the number of simulated steps of each run, \emph{Output} whether the model writes output files, \emph{Start date} and \emph{End date} the temporal range of the simulation and \emph{Platform} the HPC system on which the runs were executed. Component-specific fields such as the resolution of each active sub-model may also appear.
