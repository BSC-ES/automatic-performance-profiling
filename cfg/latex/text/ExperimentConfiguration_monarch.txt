The table below lists the configuration values that are common to all the tests in this report. Values that apply to a single test are listed in the section of that test. When present, \emph{Datelist} is the starting date of the experiment, \emph{Start hour} the initial forecast hour, \emph{Spinup hours} the number of hours reserved for model spin-up, \emph{Forecast hours} the number of forecast hours of each run and \emph{Platform} the HPC system on which the runs were executed.
